# RE:LAY

아모레몰 리필 합배송·예약형 구독(Pull) 서비스 **RE:LAY**의 클릭 프로토타입입니다.

정기배송(브랜드가 주기를 정하는 Push 방식) 대신, 소비자가 소진 시점을 직접 호출하는
예약형 구독과 합배송으로 배송비·포장재·탄소를 줄이는 컨셉을 검증하기 위한 목업입니다.

## 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

## 화면 구성

- 상품 상세 → 리필 구독 함께 신청 → 결제 → 주문 완료
- 사용 중인 리필 관리 (진행률, 알림일 변경, 회차 건너뛰기, 혜택 종료)
- 사용 상태 확인 → 리필 결제 → 합배송 선택 → 리필 주문 완료

모든 데이터는 목업이며, 브라우저 `localStorage`에만 저장됩니다.
